# Rose Garden

This is a relay script for the Rose Garden iotm of Kingdom of Loathing.

This relay script will allow you to easily submit data for a spading initiative at https://rosegarden.lib.co.nz/

The script also allows you to see the map of your garden and download it. Also to show the choices that KoL added for device compatibility, because walking is just too much.

# Install

This script requires KoLMafia to run, and you can install this script by typing into KoLMafia gCLI:

`git checkout libraryaddict/rose-garden`

# Spading Only

If you do not want the other features of this script (map, choices), and only want to contribute data to spade the puzzle, you can disable those features by typing into KoLMafia gCLI:

`set roseGarden_noCheating = true`

To enable it again, use:

`set roseGarden_noCheating = false`
